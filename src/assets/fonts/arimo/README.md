# Arimo

Local variable font for the Mr8 case page, weights 400–700; Latin and Cyrillic.

Source: https://github.com/google/fonts/tree/main/ofl/arimo
Upstream: https://github.com/googlefonts/Arimo
License: SIL Open Font License 1.1 (see OFL.txt).

Downloaded on 2026-11-16 and converted from the upstream TTF to WOFF2 using the existing ttf2woff2 dependency. Served locally, without Google Fonts API or a font CDN.
