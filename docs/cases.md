# Работа с кейсами

- HTML: `src/cases/kontur-tilda.html`.
- SCSS: `src/assets/css/cases/_kontur-tilda.scss`, уже подключён в `app.scss`.
- HTML содержит копию существующего кейса как рабочую основу. Существующий `src/case.html` не изменён.
- Шапка и подвал подключаются существующим Nunjucks-layout. Их код не менялся.

Запуск: `npx gulp`. Готовая страница: `dist/kontur-tilda.html`.

Исходники лежат в папке, а собранный HTML — в корне `dist`, чтобы существующие пути `assets/...` работали без изменений общих шаблонов. Для карточки этой страницы адрес будет `kontur-tilda.html`. Текущие карточки не менялись.

Для нового кейса скопируйте HTML и SCSS под новым уникальным именем, задайте собственный класс страницы и добавьте `@use 'cases/имя-файла';` в `app.scss`. Индивидуальные правила ограничивайте классом страницы или собственными БЭМ-блоками.

SCSS компилирует Gulp. Общие стили кейса остаются в `blocks/case.scss`; копировать их не требуется.

Проверки: `npm run check` дважды, `npm run build`, `npm run lint:html:dist`.
